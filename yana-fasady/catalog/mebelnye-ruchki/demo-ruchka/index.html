Размер по чертежу 400 × 640 мм. Модель построена строго по файлу «Базис-Мебельщик» — без допущений по размерам и профилю, поэтому другой размер здесь не подбирается.

ДЭМО · Ручка

Демонстрация 3D по файлу «Базис-Мебельщика» «Ручка». Фасад 400 × 640 × 22 мм с интегрированной ручкой: паз с поднутрением во всю ширину у верхней кромки — 20,6 мм по лицу, 31,6 мм внутри, глубина 18 мм. Кромки фасада скруглены R2. Геометрия построена прямо из файла — без перерисовки и допущений.

Цвет: Полуночный сад

Оттенок уточняем по физическому образцу.
